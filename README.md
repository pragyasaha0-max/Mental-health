# Mental Health: portfolio template

Open `index.html` for a calm, sage-green portfolio in the MindWell style (hero with floating skills card, five-fact strip, six photo cards, lake photo with counting numbers, experience cards, skills, leaf banner) with placeholder content. The sample text is the `SAMPLE` list in `page.html`; edit it and run `python3 build.py`.

- `index.html` – the page (theme, script and images inlined so it works on its own)
- `calm-sage.css` / `calm-sage.js` – the reusable theme (all classes prefixed `cm-`)
- `page.html`, `helpers.js`, `build.py` – source: page template, text parser, build script (`python3 build.py`)
- `img/` – photos cut from the design; `prep.py` is how they were cut and cleaned

Theme features: scroll reveal, word-by-word headings, counting numbers, light that travels round box borders, hover spotlight. Colours and fonts live in the first block of `calm-sage.css`.
